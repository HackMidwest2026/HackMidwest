Fight and timing

How to use it

  1. Once. Save for OBS mode and open that file in Chrome or Edge (the camera is blocked inside claude.ai). Pick the OBS projector window (or the OBS Virtual Camera), press Start watching and drag the gold box tightly around the status-bar coin. If you set the box up in the Time Out Timer file in the same browser, it is already there.
  2. Each try. In the fight, pick Power Bounce and stand on its target screen. The coin keeps spinning there; after about 25–40 s the page has the seed and starts the countdown. Confirm with A on the last (high) beep, then press A on each short beep for the bounces.
  3. Log it. Type how many bounces you got. A hit moves the target up one. Blooper only has 30 HP and every bounce costs 1, so a try for K needs at least K HP left: reload your save between rungs, or make the try for the remaining HP the last one.
  4. Where to stop. The table shows how long the next rung usually takes. Without Dodge Master Blooper tops out around 20–21 (22 takes 20+ minutes of standing), Final Bowser phase 2 around 8–9.
  5. Calibration. A one-frame miss gives an unrelated count, so until your offset is measured each rung above the easy ones lands about half the time. Once a few tries agree, press Copy calibration and paste it into the Time Out Timer (Timing settings → Use calibration); opened as files in the same browser it reads it by itself.
